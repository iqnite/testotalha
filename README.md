# 🔥 Testo Talha 🔥

Diese Python-Modul gibt eure Programme mehr TESTO checkt ihr?

## Installation

Hol dir mit pip runter:

```bash
pip install testotalha
```

## Verwendung

### Ya Herro Ya Merro

Olum ruf deine Funktionen mit mehr Aura auf, indem du `@ya` Dekorator benutzt:

```python
from testotalha import ya

@ya
def my_function():
    print(1 + "1")  # Output: SIKTIR GIT: unsupported operand type(s) for +: 'int' and 'str'

@ya
def my_other_function():
    print(1 + 1)  # Output: YA HERRO YA MERRO
```

### Testosteron

Schau richtigen TESTO Content an:

```python
from testotalha import testosteron

testosteron()
```

### Random number generator

Erstelle Zufallszahlen. Zum Beispiel, du sagst zu Chaya "Wenn 31 rauskommt musst du bei mir Otuzbir machen", und rufst du `randint(1, 40)` auf, und wenn 31 rauskommt, dann musst sie bei dir Otuzbir machen.

```python
from testotalha import randint

print(randint(1, 40))
```

### Aura

Printe Text mit mehr TESTO:

```python
from testotalha import aura

aura("Testo Talha")  # Output: 🔥 TESTO TALHA 🔥
```
